# Ancular Product Vision

Ancular is a **Travel Operating System**.

The product organizes everything about a trip into a single command center.

Users should be able to open one screen and instantly know:

- what is happening next
- where they need to go
- what documents they need
- what activities are available
- what the current situation is

The product should remove travel chaos.

---

# Core User Problem

Travel information is fragmented across:

- emails
- PDFs
- screenshots
- booking apps
- messaging threads
- maps
- weather apps

Users constantly switch between these sources.

Ancular consolidates them.

---

# Product Pillars

Ancular is built around five core pillars.

## 1. Trips

Trips are the main container for travel planning.

Trips contain:

- timeline events
- documents
- suggestions
- notes
- travel context

Trips should feel like **a workspace for travel**.

---

## 2. Timeline

Timeline items represent itinerary events.

Examples:

- flight departure
- hotel check-in
- restaurant reservation
- activity booking
- transport

Timeline items should support:

- time
- title
- notes
- location
- attached documents

The timeline acts as the **live itinerary**.

---

## 3. Documents

Travel documents must be easy to store and retrieve.

Examples:

- passport scans
- visas
- boarding passes
- hotel confirmations
- tickets
- reservations

Documents should be:

- reusable across trips
- easily attached to timeline events
- viewable or downloadable quickly

---

## 4. Smart Assistance

Ancular should provide helpful intelligence.

Examples:

- AI itinerary generation
- document recognition
- travel suggestions
- weather updates
- reminders

The goal is not to replace booking platforms.

The goal is to **organize everything after booking**.

---

## 5. Command Center

Each trip page should function as a command center.

Users should immediately see:

- next event
- travel documents
- timeline preview
- weather
- activities

The command center should reduce cognitive load.

---

# Design Philosophy

The interface should feel:

- calm
- premium
- minimal
- mobile-first
- information-dense but uncluttered

Design inspiration:

- Linear
- Apple Wallet
- Flighty
- Notion

Preferred UI patterns:

- card layouts
- strong hierarchy
- subtle motion
- large touch targets

---

# Target Users

Primary users:

- frequent travelers
- digital nomads
- business travelers
- families traveling internationally

These users manage many travel documents and bookings.

---

# Non-Goals

Ancular should NOT attempt to:

- become a booking platform
- replace airlines or hotels
- compete with travel agencies

Instead, Ancular complements those services.

---

# Key Product Features

The most important features are:

1. Smart Trip Dashboard
2. AI Itinerary Builder
3. Document Vault
4. Travel Document Scanner
5. Activity Discovery

These features should be prioritized when adding new functionality.

---

# Product North Star

Ancular should become:

**The one place travelers check before leaving home, at the airport, and throughout their journey.**

Everything about the trip should be visible in one place.
